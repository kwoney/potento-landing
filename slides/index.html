02
Pain Points

기존 앱들을 쓰며 만난 6가지 벽

🌐 언어 장벽

외국인에게는 콘텐츠 자체가 진입장벽. 한국어 아니면 영어, 한쪽만 지원

체류 외국인 278만 명 · 한국살이 고충 1위 «언어»(40%)

👻 노쇼

운영자는 당일까지 참여 인원을 예측할 수 없다 — 모임 퀄리티를 흔드는 1순위

무료 모임 노쇼율 40~60% · 문토는 «노쇼 방지비»를 따로 받는다

🎭 신뢰 · 로맨스 스캠

낯선 사람과의 1:1 만남 불안, 스캠 계정의 무차별 DM

국내 로맨스스캠 피해 1,380억 원 (2024.2~2025.7, 경찰청)

🔕 메시지를 안 본다

공지를 보내도 확인율이 낮다 — 알림 설계와 UI 배치의 문제

푸시 알림 평균 오픈율 ~20%

📅 일정 겹침

여러 모임에 참여할수록 일정 충돌을 본인도 모른다 — 운영하며 반복 관찰한 문제

💸 개설 부담

첫 그룹을 만들기까지 신경 쓸 게 너무 많고, 노출은 유료 — 운영자 진입장벽

Meetup 모임장 월 $19.99 · 소모임 월 15,500원
03
Solution

겪은 문제 → 넣은 기능

🌐 언어 장벽→콘텐츠 자동 번역 + 채팅 즉시 번역 — 초기 진입장벽부터 낮춘다
👻 노쇼→승인제 참가 · D-1 확정 리마인드 — 운영자가 인원을 예측할 수 있게
🎭 신뢰 · 스캠→1:1 DM은 신뢰 관계에서만 · 신고/차단 시 채팅 가림 · 프로필 인증 뱃지
🔕 메시지 확인→채팅 통합 탭 + 알림 범위 설계 — 봐야 할 것만 확실히 닿게
📅 일정 겹침→참가 시 겹침 경고 — 충돌을 참가 시점에 미리 알려준다
💸 개설 부담→무료 · 가벼운 그룹 개설 플로우 — 운영자 공급을 막지 않는다
